# 🛡️ Ciberseguridad desde cero: ruta de aprendizaje con recursos gratuitos

Ruta ordenada de principiante a especialista, usando solo recursos gratuitos.
Tiempo estimado: **12 a 14 meses** dedicando unas horas a la semana.

> ⭐ Si te sirve, dale una estrella al repositorio para que más gente lo encuentre.

---

## 🗺️ Vista general

| Fase | Meses | Objetivo |
|------|-------|----------|
| 0-1 · Fundamentos | 1-4 | Redes y Linux |
| 2 · Seguridad defensiva básica | 4-8 | OWASP, SOC y análisis de tráfico |
| 3 · Especialización | 8-14 | Elegir rama: ofensiva, defensiva o cloud |
| Certificaciones | Según avances | Validar conocimientos |

---

## 📌 Fase 0-1: Fundamentos (meses 1-4)

- [ ] **Redes básicas** — Cisco Networking Academy (curso gratuito)(https://www.netacad.com/) · o el canal de YouTube "Fabián Zambrano" · Español
- [ ] **Linux desde cero** — [Linux Journey](https://linuxjourney.com) · o el "Curso de Linux" de freeCodeCamp en YouTube
- [ ] **Redes intermedio (Network+)** — Material gratuito de Professor Messer en YouTube · Inglés con subtítulos

## 📌 Fase 2: Seguridad defensiva básica (meses 4-8)

- [ ] **OWASP Top 10** — [owasp.org](https://owasp.org) · Fuente oficial y gratuita
- [ ] **Introducción a SOC y seguridad** — TryHackMe, rutas gratuitas "Pre Security" e "Introduction to Cyber Security" (https://tryhackme.com/room/redteamengagements)
- [ ] **Análisis de tráfico** — Wireshark (herramienta gratuita) y los tutoriales oficiales de su web

## 📌 Fase 3: Especialización (meses 8-14)

Elige una rama:

### 🔴 Ofensiva / Pentesting / Red Team
- [ ] TryHackMe: rutas gratuitas de hacking ético (https://tryhackme.com/room/redteamengagements)
- [ ] HackTheBox: máquinas gratuitas para practicar _(https://www.hackthebox.com/get-started)
- [ ] YouTube: **TheGoodHacker** (Kali Linux, hacking ético y red team desde nivel principiante)

### 🔵 Defensiva / SOC / GRC
- [ ] TryHackMe: rutas de monitoreo y respuesta a incidentes
- [ ] [OWASP.org](https://owasp.org): buenas prácticas y cumplimiento

### ☁️ Cloud Security
- [ ] AWS Free Tier (cuenta gratuita durante 12 meses)
- [ ] Curso oficial gratuito "AWS Cloud Practitioner Essentials", con módulos de seguridad

---

## 🎓 Certificaciones recomendadas (en orden)

1. **CompTIA Security+** — Entrada y reconocida globalmente. La preparación es gratis con Professor Messer; el examen tiene costo.
2. **eJPT** — Práctica ofensiva, certificación económica.
3. **CySA+ o SC-900** — Si te inclinas por lo defensivo o el cloud.
4. **OSCP** — Nivel avanzado, muy respetada y no exige título. Llega aquí con una base sólida.

## 💼 Portafolio práctico

- Documenta en GitHub o en un blog tus **writeups** de máquinas resueltas en TryHackMe y HackTheBox.
- Participa en **CTFs (Capture The Flag)** gratuitos: son tu experiencia demostrable sin necesidad de trabajo formal previo.

## ⚠️ Aviso ético y legal

Practica hacking **solo** en entornos autorizados (TryHackMe, HackTheBox, laboratorios propios y CTFs). Atacar sistemas sin permiso es ilegal.
